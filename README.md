# CAFE

Closed-Loop Autonomous Task Formulation and Execution without Instance-Specific Instructions.

Anonymous materials for review.

- [Project homepage](https://submissionforpaper.github.io/CAFE-Closed-Loop-Autonomous-Task-Formulation-and-Execution-without-Instance-Specific-Instructions/)
- [Implementation repository](https://github.com/submissionforpaper/CAFE-Closed-Loop-Autonomous-Task-Formulation-and-Execution-without-Instance-Specific-Instructions)

## Source code

The implementation is included in CAFE/. The main entry point is CAFE/aithor2/main_with_depth.py.

Install dependencies:

~~~bash
pip install -r CAFE/aithor2/requirements.txt
pip install -r "CAFE/aithor2/embodied B1/requirements.txt"
~~~

Configure your own API credentials before running the experiments.
